## 📌 这个仓库是什么？

通过类似 Python Puzzles 的互动方式学习 Triton 编程。每个 puzzle 是一个需要你填充的 Triton Kernel 模板。

## 🎯 为什么对 AI Infra 重要？

1. **动手学习 Triton** — 最佳的学习方式
2. **面试准备** — Puzzle 中的 Kernel 是面试常见题
3. **理解 GPU 编程模式** — 每个 puzzle 对应一种编程模式

## 🔑 精髓：Puzzle 列表

| Puzzle | 主题 | 面试考点 |
|--------|------|----------|
| Puzzle 1-3 | 向量操作 | Triton 基础 |
| Puzzle 4-6 | 归约 | 归约算法 |
| Puzzle 7-9 | 矩阵乘法 | GEMM 优化 |
| Puzzle 10-12 | Attention | Flash Attention |
| Puzzle 13-15 | 融合算子 | 算子融合 |

## 📖 推荐学习路径

1. 先学 Triton 基础（tutorial）
2. 按顺序完成 Puzzle
3. 理解每个 Puzzle 对应的 GPU 编程模式
4. **动手**：自己设计一个新的 Puzzle
