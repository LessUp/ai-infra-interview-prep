## 📌 这个仓库是什么？

NVIDIA Triton Inference Server 的官方教程，展示如何部署各种模型到 Triton 服务器上。

## 🎯 为什么对 AI Infra 重要？

1. **了解生产级推理服务** — Triton 是 NVIDIA 的推理服务器
2. **理解模型部署** — 模型如何从文件到服务
3. **与 TensorRT-LLM 配套** — Triton 是 TensorRT-LLM 的部署平台

## 🔑 精髓：核心概念

- **Model Repository** — 模型存储结构
- **Backend** — 不同的推理后端（TensorRT, PyTorch, ONNX 等）
- **Dynamic Batching** — 动态批处理
- **Model Ensemble** — 模型流水线
