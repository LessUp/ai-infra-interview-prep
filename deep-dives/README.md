## 使用说明

1. **快速抓住重点** — 知道每个仓库的核心价值在哪里

3. **面试准备** — 每个仓库都标注了对应的面试考点
4. **动手实践** — 每个仓库都提供了可执行的练习

## 阅读建议

1. **先读核心再读辅助** — 核心仓库是面试的基石
2. **每个仓库先看本文档的"精髓"部分** — 了解核心思想后再看源码
3. **配合源码阅读** — 本文档告诉你读什么，源码告诉你细节
4. **做笔记** — 每个仓库的"练习"部分帮助你巩固理解
