## 📌 这个仓库是什么？

GPU Mode 社区（由 CUDA Mode 创始人 Mark Saroufim 等发起）的讲座材料，涵盖 GPU 编程的各个方面：从 CUDA 基础到 Triton、Flash Attention、量化等。

## 🎯 为什么对 AI Infra 重要？

1. **系统性学习** — 从基础到高级的完整课程
2. **社区驱动** — 来自工业界的最佳实践
3. **配套视频** — 每个讲座都有对应的 YouTube 视频
4. **持续更新** — 跟踪 GPU 编程的最新发展
